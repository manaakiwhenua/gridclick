about=Gridclick adds a map tool that previews the DGGS cell under the cursor at the chosen resolution and creates a feature on click. Store the cell ID alone (as both string and int64), a point, a polygon, or a point+polygon geometry collection. A class palette lets one click also write label attributes (keys 1-9 switch class), which makes the plugin usable for building cell-based training data; re-clicking a labelled cell re-labels it rather than duplicating it. Each target layer is locked to a single DGGS. Requires the Python packages listed in requirements.txt (h3, s2sphere, pya5, rhealpixdggs, pygeohash) — each DGGS is enabled independently depending on what is installed.
